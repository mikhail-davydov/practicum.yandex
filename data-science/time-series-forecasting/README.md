# Прогнозирование временных рядов

## Описание

Проект по прогнозированию временных рядов на примере данных о заказах такси. Решение задачи предсказания количества заказов такси в зависимости от времени.

## Основная задача

Построение модели машинного обучения для прогнозирования количества заказов такси на ближайшее время (час, день) на основе исторических данных.

## Файлы

| Файл | Описание |
|------|----------|
| [`taxi.ipynb`](taxi.ipynb) | Jupyter Notebook с анализом временных рядов и построением модели прогнозирования заказов такси |

## Используемые технологии

- Python
- Pandas
- Scikit-learn
- XGBoost
- Statsmodels
- Matplotlib / Seaborn

## Описание данных

Датасет содержит данные о заказах такси:
- Временные метки (дата и время)
- Количество заказов
- Географическая информация
- Погодные условия
- Праздничные дни
- День недели

## Методы прогнозирования

Проект включает использование различных методов:
- **ARIMA / SARIMA** — классические статистические методы
- **Градиентный бустинг** — XGBoost, LightGBM
- **Feature Engineering** — создание признаков из временного ряда
- **Кросс-валидация** — проверка качества модели на временных рядах

## Применение

Модель прогнозирования может использоваться:
- Для планирования количества машин
- Оптимизации работы водителей
- Ценообразования в пиковые часы
- Планирования маркетинговых кампаний
- Управления ресурсами компании
