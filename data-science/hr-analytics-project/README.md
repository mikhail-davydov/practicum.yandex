# HR-аналитика

## Описание

Проект по аналитике человеческих ресурсов. Решение задач по прогнозированию оттока сотрудников и анализу факторов, влияющих на удовлетворённость и удержание персонала.

## Основная задача

Построение модели машинного обучения для предсказания вероятности увольнения сотрудника и выявления ключевых факторов, влияющих на текучесть кадров.

## Файлы

| Файл | Описание |
|------|----------|
| [`hr-analytics.ipynb`](hr-analytics.ipynb) | Jupyter Notebook с полным анализом HR-данных и построением модели предсказания оттока сотрудников |

## Используемые технологии

- Python
- Pandas
- Scikit-learn
- XGBoost
- Matplotlib / Seaborn

## Описание данных

Датасет содержит информацию о сотрудниках:
- Демографические данные (возраст, пол, образование)
- Рабочие показатели (уровень удовлетворённости, оценки производительности)
- Информация о трудоустройстве (отдел, должность, стаж)
- Уровень дохода
- Количество проектов
- Баланс работа/личная жизнь

## Метрики модели

Основные метрики для оценки качества модели:
- Accuracy (точность)
- Precision (полнота)
- Recall (полнота)
- F1-score
- ROC-AUC

## Бизнес-ценность

Результаты анализа помогают:
- Снизить текучесть кадров
- Оптимизировать затраты на подбор персонала
- Выявить неудовлетворённых сотрудников
- Принять обоснованные решения о повышении зарплаты или продвижении
