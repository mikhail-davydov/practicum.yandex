# Обработка естественного языка (NLP)

## Описание

Проект по обработке естественного языка на примере данных интернет-магазина WikiShop. Решение задач по анализу текстовых отзывов и описаний товаров.

## Основная задача

Построение модели машинного обучения для анализа текстовых данных — классификации отзывов, определения тональности, извлечения сущностей или других задач NLP.

## Используемые технологии

- Python
- NLTK
- SpaCy
- TensorFlow / Keras
- Scikit-learn
- Gensim (Word2Vec)

## Описание данных

Датасет содержит текстовые данные интернет-магазина WikiShop:
- Отзывы покупателей
- Описания товаров
- Категории товаров
- Рейтинги и оценки

## Типичные задачи NLP

Проект включает решение следующих задач:
- **Классификация текста** — определение категории товара или типа отзыва
- **Анализ тональности** — определение позитивного или негативного отзыва
- **Извлечение сущностей** — выделение именованных сущностей из текста
- **Модели эмбеддингов** — использование Word2Vec или подобных моделей
- **Тематическое моделирование** — выделение тем в текстах

## Применение

Результаты могут использоваться для:
- Автоматической модерации отзывов
- Рекомендаций товаров
- Анализа удовлетворённости клиентов
- Поиска по текстовому описанию
