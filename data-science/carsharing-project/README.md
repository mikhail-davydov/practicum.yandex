# Проект каршеринга

## Описание

Проект по анализу данных каршерингового сервиса. Решение задачи предсказания спроса на автомобили каршеринга в зависимости от различных факторов.

## Основная задача

Построение модели машинного обучения для прогнозирования количества активных пользователей каршеринга в конкретный момент времени на основе исторических данных и внешних факторов.

## Файлы

| Файл | Описание |
|------|----------|
| [`carsharing.ipynb`](carsharing.ipynb) | Jupyter Notebook с полным анализом данных и построением модели прогнозирования спроса |

## Используемые технологии

- Python
- Pandas
- Scikit-learn
- Matplotlib / Seaborn

## Описание данных

Датасет содержит информацию о поездках каршеринга:
- Временные метки поездок
- Географическое положение
- Продолжительность поездки
- Стоимость
- Тип автомобиля
- Погодные условия
- День недели / праздничные дни
