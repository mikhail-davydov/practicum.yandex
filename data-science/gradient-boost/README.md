# Градиентный бустинг

## Описание

Проект по предсказанию стоимости автомобилей с использованием алгоритмов градиентного бустинга. Решение задачи регрессии для определения рыночной цены автомобиля на основе его характеристик.

## Основная задача

Построение модели машинного обучения для предсказания стоимости автомобиля по техническим характеристикам и другим параметрам с использованием методов градиентного бустинга.

## Файлы

| Файл | Описание |
|------|----------|
| [`carprice.ipynb`](carprice.ipynb) | Jupyter Notebook с анализом данных и построением модели предсказания цены автомобиля |

## Используемые технологии

- Python
- XGBoost
- LightGBM
- CatBoost
- Scikit-learn
- Pandas
- Matplotlib / Seaborn

## Описание данных

Датасет содержит информацию об автомобилях:
- Технические характеристики (год выпуска, пробег, объём двигателя)
- Марка и модель автомобиля
- Тип кузова
- Тип топлива
- Коробка передач
- Привод
- Состояние автомобиля

## Алгоритмы градиентного бустинга

В проекте используются современные реализации градиентного бустинга:
- **XGBoost** — экстремальный градиентный бустинг
- **LightGBM** — градиентный бустинг на основе гистограмм
- **CatBoost** — градиентный бустинг с поддержкой категориальных признаков
