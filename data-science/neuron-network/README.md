# Нейронные сети

## Описание

Проект по применению нейронных сетей для решения задачи предсказания температуры звёзд. Демонстрация использования глубокого обучения для работы с астрономическими данными.

## Основная задача

Построение модели нейронной сети для предсказания температуры поверхности звёзд на основе их характеристик.

## Файлы

| Файл | Описание |
|------|----------|
| [`stars-temperature.ipynb`](stars-temperature.ipynb) | Jupyter Notebook с разработкой и обучением нейронной сети для предсказания температуры звёзд |

## Используемые технологии

- Python
- TensorFlow / Keras
- NumPy
- Pandas
- Matplotlib / Seaborn
- Scikit-learn

## Описание данных

Датасет содержит астрономические данные о звёздах:
- Спектральный класс
- Светимость
- Радиус
- Абсолютная звёздная величина
- Цвет (показатель)
- Температура (целевая переменная)

## Архитектура нейронной сети

Проект включает:
- Полносвязные слои (Dense layers)
- Функции активации (ReLU, Sigmoid)
- Оптимизаторы (Adam, SGD)
- Функции потерь для регрессии (MSE)
- Регуляризация (Dropout, L2)

## Применение

Подобные модели могут использоваться:
- В астрономических исследованиях
- Для классификации звёзд
- При анализе больших массивов астрономических данных
- В научных публикациях
