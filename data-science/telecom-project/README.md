# Телекоммуникационная аналитика

## Описание

Проект по анализу данных телекоммуникационной компании. Решение задач по прогнозированию оттока клиентов и оптимизации бизнес-процессов в сфере связи.

## Основная задача

Построение модели машинского обучения для предсказания вероятности оттока клиентов (churn prediction) и выявления факторов, влияющих на решение клиентов об уходе.

## Файлы

|------|----------|
| [`telecom.ipynb`](telecom.ipynb) | Jupyter Notebook с полным анализом данных и построением модели предсказания оттока клиентов |

## Используемые технологии

- Python
- Pandas
- Scikit-learn
- XGBoost
- LightGBM
- Matplotlib / Seaborn

## Описание данных

Датасет содержит информацию о клиентах телекоммуникационной компании:
- Демографические данные (возраст, пол, семейное положение)
- Географическое расположение
- Тип контракта
- Услуги (интернет, телефон, ТВ)
- Финансовые данные (стоимость услуг, способ оплаты)
- История использования услуг
- Статус клиента (отток/остался)

## Метрики модели

Основные метрики для оценки качества модели:
- Accuracy (точность)
- Precision (полнота)
- Recall (полнота)
- F1-score
- ROC-AUC

## Бизнес-ценность

Результаты анализа помогают:
- Снизить отток клиентов
- Оптимизировать маркетинговые расходы
- Выявить неудовлетворённых клиентов
- Принять решения о улучшении услуг
- Персонализировать предложения для клиентов
