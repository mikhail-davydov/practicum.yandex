# Big Data и Spark

## Описание

Проект по обработке больших данных с использованием Apache Spark. Решение задачи предсказания стоимости жилья в Калифорнии на основе данных о домах и их характеристиках.

## Основная задача

Построение модели машинного обучения для предсказания медианной стоимости домов в различных районах Калифорнии. Используются распределённые вычисления через Apache Spark для эффективной обработки больших объёмов данных.

## Используемые технологии

- Apache Spark
- PySpark
- Машинное обучение (MLlib)

## Описание данных

Датасет содержит информацию о жилых объектах в Калифорнии, включая:
- Географическое положение (широта, долгота)
- Количество комнат и спален
- Population и количество домохозяйств
- Доход населения в районе
- Медианная стоимость жилья (целевая переменная)
