# Поиск фотографий по текстовому описанию

## Описание

Проект по разработке системы поиска изображений по текстовому запросу. Решение задачи компьютерного зрения и обработки естественного языка для создания мультимодальной системы поиска.

## Основная задача

Построение модели машинного обучения, которая по текстовому описанию может находить релевантные изображения из базы данных.

## Используемые технологии

- Python
- TensorFlow / Keras
- PyTorch
- CLIP (OpenAI)
- NumPy
- PIL (Pillow)

## Описание данных

Датасет содержит:
- Коллекцию изображений
- Текстовые описания к изображениям
- Метки и категории
- Атрибуты изображений

## Подходы к решению

Проект использует современные методы:
- **CLIP (Contrastive Language-Image Pre-Training)** — модель, обученная понимать связь между изображениями и текстом
- **Векторные представления** — эмбеддинги изображений и текста
- **Косинусное сходство** — метрика для поиска похожих изображений
- **Трансферное обучение** — использование предобученных моделей

## Применение

Система может использоваться:
- В интернет-магазинах для поиска товаров по описанию
- В фотобанках и стоковых сервисах
- В системах управления контентом
- Для автоматической аннотации изображений
- В приложениях для людей с ограниченными возможностями
