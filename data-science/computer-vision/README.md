# Компьютерное зрение

## Описание

Проект по распознаванию и валидации изображений с использованием методов компьютерного зрения. Решается задача определения возраста человека по фотографии.

## Основная задача

Построение модели машинного обучения для предсказания возраста человека по изображению лица. Модель используется для валидации возраста в различных сервисах.

## Файлы

| Файл | Описание |
|------|----------|
| [`age-validation-model.ipynb`](age-validation-model.ipynb) | Jupyter Notebook с разработкой и обучением модели определения возраста |

## Используемые технологии

- Python
- TensorFlow / Keras
- OpenCV
- PIL (Pillow)
- Scikit-learn

## Описание данных

Датасет содержит изображения лиц людей с различными характеристиками:
- Фотографии лиц различного возраста
- Аннотации с указанием возраста
- Разнообразие по полу, этнической принадлежности
- Различные условия освещения

## Применение

Модель может использоваться в различных сервисах:
- Верификация возраста при регистрации
- Ограничение доступа к контенту
- Персонализация рекламы
- Системы безопасности
