# Docker

## Описание

Сборник полезных Dockerfile-конфигураций для запуска различных инструментов машинного обучения и обработки данных в контейнерах Docker. Использование контейнеров позволяет обеспечить воспроизводимость окружения и упрощает развёртывание проектов.

## Подразделы

| Директория | Описание |
|------------|----------|
| [jupyter-spark](./jupyter-spark/README.md) | Jupyter Notebook с предустановленным Apache Spark для обработки больших данных |

## Зачем использовать Docker

- **Воспроизводимость**: одинаковое окружение на всех машинах
- **Изоляция**: независимость от системных зависимостей
- **Простота развёртывания**: быстрый запуск готовых решений
- **Портативность**: работа на любой ОС с Docker

## Быстрый старт

### Требования

- Docker Desktop (Windows/Mac)
- Docker Engine (Linux)
